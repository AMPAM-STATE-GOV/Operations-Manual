# Gov Dashboard

The ADDIF Government Dashboard is the central operating interface for all AMPAM officials. Access at /gov.html with your official credentials (username + ampam2026).

The dashboard contains 11 department tabs: Executive, MOFA, Consular, Secretary of State, Revenue, Post, Credit Union, Surety, Land Bank, Insurance, Waqf. Every official sees all departments — there are no restricted views.

Sub-tabs within each department: Overview (metrics and stats), Nationals (registry of all nationals), Controlled Records (all registered instruments), Tools (78 sovereign instrument generators), Documents (upload, classify, sign, transfer, track), Pages (Notion-style document editor with markdown and version history), Messages (DIME — signed digital instrument messaging), Memo Board (government bulletin board), AMPAM Records (catalog pipeline view), Born Recording (sovereign birth instrument form), National Pledge (Madrid Article 15 re-entry pledge), Legislation (bill creation and enactment), Public Notices (international notice publication).

The AI Chat Assistant (gold button bottom-right) provides treaty references, constitutional guidance, and system navigation help.

All department functions are accessible to all officials. The system enforces governance through workflow gates, not access restrictions.
